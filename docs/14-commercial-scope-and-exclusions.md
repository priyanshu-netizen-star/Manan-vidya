# Commercial scope and exclusions

## Proposed project fee

| Item | Amount |
|---|---:|
| Discovery, requirements and solution design | ₹20,000 |
| AI-powered learning pilot | ₹80,000 |
| ERP workflow and administration automation | ₹75,000 |
| AI admissions assistant and lead tracking | ₹60,000 |
| Digital hostel management | ₹55,000 |
| Testing, training, documentation and handover | ₹25,000 |
| Project coordination and initial support | ₹20,000 |
| **Sum of line items above** | **₹3,35,000** |
| *Not yet allocated to a line item, to be reconciled by VoxVision before the proposal is issued* | *₹15,000* |
| **Total proposed project fee** | **₹3,50,000** |

The fee is a fixed price for the scope described in this proposal and the *Feature catalogue*. Taxes, if applicable, are as stated in the agreement.

## Payment milestones

| Milestone | Share | Amount | When |
|---|---:|---:|---|
| Project start | 40% | ₹1,40,000 | On signing the agreement and project kick-off |
| Core pilot review | 30% | ₹1,05,000 | AI learning pilot and admissions assistant reviewed by the school |
| Module review | 20% | ₹70,000 | Administration and hostel modules reviewed by the school |
| Final handover | 10% | ₹35,000 | Training, documentation and handover completed |
| **Total** | **100%** | **₹3,50,000** | |

## Included

- Discovery workshops, written scope, acceptance criteria and data-protection plan.
- Set-up and configuration of the seven modules for the school's classes, roles and workflows.
- Loading of school-approved learning material and admissions information with staff (agreed volumes).
- One-time import of students, classes and staff from the school's export, where available (agreed volumes).
- Role-based accounts, security configuration and audit logging.
- Testing with staff, training per role, user manuals and handover documentation.
- Project coordination and initial support for the period agreed in the contract.

## Not included (unless agreed in writing)

- Hardware of any kind: computers, tablets, robotics kits, sensors, networking or biometric devices.
- External subscriptions and hosting or database plans.
- AI / API consumption charges (for example Claude or Gemini API usage), billed by the provider on actual use.
- SMS, WhatsApp or other messaging charges.
- Third-party ERP licences, vendor integration fees or vendor API access charges.
- Data migration beyond the agreed one-time import; data entry.
- Physical robotics workshops, on-site trainers, or equipment procurement.
- New features beyond the agreed scope; integrations beyond the option agreed after discovery.
- Any other cost not explicitly agreed in writing.

The fee does not include unlimited functionality, hardware or third-party services.

## To be agreed in the contract

- Final scope of each module and its acceptance criteria.
- Production hosting and deployment responsibilities.
- Source-code licensing or ownership and intellectual-property terms.
- Duration and level of support after handover, and maintenance terms after that.
- Data-protection responsibilities of the school and VoxVision.
- Change-request process and rates for work outside scope.
