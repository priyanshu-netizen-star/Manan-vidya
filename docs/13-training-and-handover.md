# Staff training and handover plan

## Training approach

- **Role-based**: each group learns only what they use.
- **Hands-on**: training is done in a training copy with sample data, then repeated on the live system with the school's own records.
- **Short sessions**: 45–90 minutes, in English or Hindi as preferred.
- **Champions**: one trained "champion" per department supports colleagues after go-live.

## Sessions

| Session | Audience | Length | Content | Outcome |
|---|---|---|---|---|
| 1. Overview for management | Principal, management | 60 min | Modules, command centre, approvals, reports, audit, data protection | Management can read the dashboard and approve content |
| 2. Teacher workspace | Teachers | 90 min | Material, question bank, AI drafting and review, quizzes, worksheets, lesson plans, performance | Each teacher publishes one quiz |
| 3. Registers and marks | Class teachers, subject teachers | 45 min | Attendance, marks entry, report cards | Each teacher saves a register and marks |
| 4. Admissions | Office, admission counsellor | 60 min | Enquiry routine, escalations, knowledge base, tracking | Staff handle an enquiry end to end and update an answer |
| 5. Records and exams | Office | 60 min | Student records, exams, locking, report cards, reports, tasks | Office prints report cards and exports a report |
| 6. Hostel | Wardens | 60 min | Leave decisions, check-out and return, roll-call, rooms, maintenance | Warden completes a full leave cycle and roll-call |
| 7. Students | Pilot classes (in computer lab) | 40 min | Learning, asking safely, quizzes, progress, coding activities | Students complete a quiz and a coding challenge |
| 8. Parents | Parents (optional, at a PTM) | 20 min | Progress, report cards, leave requests, admissions help | Parents can sign in and submit a request |
| 9. Administrator | Nominated school administrator | 90 min | Users and roles, audit, system status, backups, support process | Administrator creates and deactivates an account |

## Materials provided

- User manuals (this documentation) and one-page quick guides per role.
- Short screen recordings of the main tasks (if agreed).
- Training attendance sheet.

## Handover package

| Item | Detail |
|---|---|
| Application access | Administrator accounts on the production system |
| Documentation | This package, including deployment and maintenance guide |
| Configuration record | Environment settings (without secret values), hosting and database details, backup schedule |
| Credentials | Transferred through a secure channel agreed with the school; changed after handover where the school controls the accounts |
| Source code | As agreed in the contract (licence or ownership terms) |
| Acceptance record | Signed acceptance against the agreed criteria |
| Support contacts | Support channel, hours and response targets for the agreed support period |

## Initial support

- Duration and response times as agreed in the contract.
- Covers: fixing defects in the delivered scope, help with how-to questions, minor configuration changes.
- Does not cover: new features, extra integrations, hardware, third-party service charges or data entry, unless agreed in writing.
- After the support period, ongoing maintenance can be agreed separately.
